关于 Pruner Studio

曲库索引、播放历史和设置保存在本机应用数据目录。

音质与播放效果

按所选音质请求网易云原曲；仅展示服务端实测返回的格式与采样率。

响度均衡

减少歌曲之间的音量差异，适用于本机转播的音频。

直连音源 · 音效旁路

两首歌曲都使用本机流地址时，切歌会短暂重叠播放。

沉浸歌词景深虚化

在全屏舞台对远离当前句的歌词施加柔和景深模糊，悬停即恢复清晰。

低频律动封面光晕

播放本机同源音频流时，封面呼吸光晕随低频能量轻微律动。

AMLL 社区逐字歌词补全

歌曲缺少逐字时间时，从 AMLL 社区查找歌词。

Windows 全局媒体快捷键

后台响应 Ctrl+Alt+→/← 切歌、↑/↓ 音量、M 静音、P 播放/暂停、L 红心、D 桌面歌词、K 穿透锁、G 游戏护航。

游戏护航模式

打游戏边听歌时冻结流光背景、模糊与过渡动画，降低 GPU/内存占用并配合穿透字幕与全局热键。

私人漫游“不想听”同步至云端垃圾桶

在私人漫游点击“不想听”时，同时通知网易云 FM 垃圾桶（受风控冷却限制）。
