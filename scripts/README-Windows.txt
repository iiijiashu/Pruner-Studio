Pruner Studio for Windows x64

安装版：双击 win64-setup.exe，按提示安装，然后从开始菜单打开。
便携版：将整个 ZIP 解压到固定文件夹，双击 Pruner-Studio.exe。
可选：在解压目录的 PowerShell 中运行 .\install-start-menu.ps1 创建开始菜单快捷方式。
桌面窗口使用 Microsoft Edge WebView2 Evergreen Runtime。缺少时可用默认浏览器访问本机界面。
官方下载：https://developer.microsoft.com/microsoft-edge/webview2/
在右上角账号菜单中扫码添加或切换网易云账号。「设置与同步」支持手动检查更新。
